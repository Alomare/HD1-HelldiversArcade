# Helldivers Arcade

Arcade game modes for HELLDIVERS (2015), for the [Obsidian](https://github.com/Alomare/ObsidianLauncher) mod manager. The first mode is Super Earth Survivors.

## Super Earth Survivors

A mode inspired by Vampire Survivors. Squads drop on an open map and hold out against waves that grow stronger over time. A second faction joins at 6 minutes and a third at 12, with elites, bosses and bombardments along the way.

Kills drop research samples. Each level up pauses the fight, refills health and lets every player pick 1 of 3 upgrade cards. Every 3rd level adds a stratagem. Some upgrades pair up and evolve into a stronger one. The shuttle can be called after 15 minutes, and a run summary shows at the end.

## How to use

Open the galaxy map and pick the **ARCADE** tab, next to Proving Grounds. Choose the faction, difficulty and biome, then Launch. The next drop replays the same mission until you pick a campaign mission.

Arcade missions don't change the Galactic Campaign.

## Playing with others

Until the host picks an arcade mission, the mod acts as a client mod and anyone can join. Arcade missions need every player in the lobby to run Helldivers Arcade at the same version.
