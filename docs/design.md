# Helldivers Arcade: design

A HELLDIVERS (2015) game mode after Vampire Survivors, for [Obsidian Mod Manager](https://github.com/Alomare/ObsidianModManager). Groundwork: what's decided, and why.

## The mode

1. The squad drops on an open map. The alarm goes on as the squad lands and stays on (`src/alarm.lua`), and the director starts spawning 20 seconds in. No enemy raises an alarm: one that spots the squad attacks at once.
2. Enemies drop XP orbs when they die. Walking over an orb fills the team's XP bar. If orbs turn out not to work, kills give the XP directly.
3. A full bar levels the team up. The game pauses on every machine in the lobby, as the game's pause menu does, every player is invulnerable, and each player gets three upgrade cards. Health refills.
4. Each local player picks from their own row of cards, all at the same time. The game resumes once every player in the lobby has picked.
5. Cards have a rarity: common, rare or legendary. Each has an icon, a name and a description.
6. The longer the squad survives, the more enemies come and the stronger they are, from all three factions, up to bosses.
7. At 15 minutes the shuttle can be called, and nothing forces the squad to: enemies keep coming, and past 20 minutes a boss comes every 5. Getting on it ends the mission the way the game does, and the game pays what it pays. Obsidian keeps the war reports out of every mission Survivors' content runs in.
7. Opening the map shows the upgrades a player has over their HUD card, as badges with their stacks in the top right corner; with the map closed, a panel from the card's left edge shows the player's health (current / maximum) and armor (`src/cards_hud.lua`). Both panels copy the card's look (`Hud.draw_panel`: `basicbox_01` at 150 of 255, the image's edge pixels as a frame outside the box), so with the card's x and width they line up with the card edge for edge. While the game lists stratagems on cooldown over the card (`Hud.draw_stratagem_cooldown_list`, hooked to see when it has something to show), the stats sit above the highest point of that list's icons, hop included; otherwise just over the card. While Obsidian API's `photo_mode` effect is on (Photo Mode turns it on), the run draws nothing on the canvas: no bar, no stats, no upgrades, no cards, no sample glow. The samples are props in the level and keep in line with the orbs, and the run's logic goes on.
8. With no reinforcements left, a player gets one back after 3 minutes, shown as a cooldown on the Reinforce stratagem. The last death with none left still fails a solo mission.
9. A kill drops an ammo box one time in twenty: the host rolls for every kill, so a box comes once for the lobby, and past ten boxes the one furthest from the squad goes. The map keeps none of its own research samples.
10. The map keeps the game's own count of objectives, of six kinds only: Exterminate, Activate and Defend Launchpad, Assassinate, Capture Area, Activate SAM Site and Activate Truth Transmitter (`src/level.lua` filters the candidates of `GeneratedLevel.generate_mission`). Each one done gives the squad 25 samples. Done, they stay done.
11. At 15 minutes the objectives leave the list, which then shows only the extraction. The shuttle needs them done, so the host completes them four seconds later, once every machine's clock is past 15:00, and every machine takes that change as no change: no banner, no music, no "objective completed" event.
12. The run says two things in the hint box: a faction joining, and the shuttle. The game's own hints stay out of a Survivors mission. The game holds a hint back while the objective list shows, and the run keeps the list up, so in a Survivors mission the hint goes first and the list makes way while it shows.

## How it fits the game

### Starting a Survivors mission

Every machine builds the map from one number, the mission seed (`DifficultySettings.get_mission_params`). The seed's low seven digits pick the time of day, light, planet type, variant, faction, mission type and difficulty. The part above them is free.

A Survivors seed is a normal mission seed with `97` above those digits: `97 * 10^7 + params`. Every machine reads the same seed, so each one knows the mission is Survivors without any message between them.

On the ship, the host's `StateMenu.get_mission_seed` decides what the drop pods start. While Survivors is chosen, the mod answers with a Survivors seed, and the game's own launch does the rest, lobby included. The mod writes nothing to the save.

To start, the host takes the galaxy map's ARCADE tab, before Proving Grounds, which flies the camera onto the planet as Proving Grounds does and shows three panels instead of mission markers (`src/entry.lua`): Game Mode (Super Earth Survivors), Parameters (starting faction, difficulty 1 to 15 with the colored cells of the game's difficulty bar under its selector, and biome, with Refresh and Launch at the bottom) and Mission Preview (the map, tall enough for a square map turned 45 degrees, with the planet's name in its top left corner, and the objectives the generated map holds, scrolled when more than three, with the scroll arrows in a column of their own). Back asks the game's leaving question in the Arcade's words: the game reads them as Back is pressed, so `entry.back` swaps them in there too. Up and down move between rows, left and right change a value, Select on a value moves to Launch, the shoulder buttons switch panels, and the mouse picks and steps values. A changed value rebuilds the preview after 0.3 s. Refresh (the reload key, the key guide's Refresh, or a click) rolls a new map for the same parameters: the game reads five of the seed's digits modulo a count, so another spelling of the same digits gives the same mission on a different map, about a thousand per set of parameters (`seed.make`'s `layout`). Launch (Select on the button, a click, or the key guide's Launch, which is the game's Select relabeled) picks the mission the game's way: the Proving Grounds screen's Select sets the galaxy map's selected trial and calls its exit, which starts the content ([Multiplayer](#multiplayer)), lends the hellpods a planet and sets the Survivors seed; the next frame's loadout takes two stratagems beside the fixed ones. A refused start keeps the galaxy map open. Nothing else on the screen launches. After a Survivors mission the next drop is the same mission and the ship stays on the mission's planet, until a campaign mission is picked or the galaxy map is left from the fronts.

### The campaign stays as it was

The hellpods open only with a planet in the save (`StateMenu.update_host`), so a Survivors drop lends them one (`src/campaign.lua`): the player's own when it's on the mission's front, or else a copy of a campaign planet with a mission left. The lent planet sits in the save only while `update_host` runs, and the save goes back to the player's own planet, or none, right after. Leaving the galaxy map with a Survivors mission saves no planet (`set_current_planet_on_exit` is off).

The game's mission end does the campaign work from the save's current planet (`StateMissionEnd.on_enter` and `save_stats`, the first host only): it marks the selected mission done, finishes the planet after the last mission, completes defend and attack events, and adds the mission's numbers to the planet. For a Survivors mission the screen sees no current planet, so it does none of that, and a machine that took over as host doesn't count the mission as the planet's last. The campaign's keys are copied before and put back after, in case anything else changes them. Obsidian's loader keeps the war reports and the CampaignManager uploads out of every mission the content runs in. `tests/test_campaign.lua` runs a copy of the game's mission end and fails on any Survivors line that writes a campaign key.

### The map

`GeneratedLevel` lays out the map from the seed. For a Survivors seed the mod:

- skips `generate_mission`, so no objectives are placed. Set pieces, samples and the extraction point stay.
- loads all three race packages in `load_resources`, on every machine, before the mission starts. Boss Variety loads a second race package this way, and Obsidian API's `load_faction` loads one mid-mission when playing alone.

Map size and shape come from the planet type's settings (`GeneratedLevelSettings`). They can be changed per seed, which is for later.

### Enemies

The host runs a director; the second faction joins at 6 minutes and the third at 12, with a hint for each. It works in waves: for 30 seconds it spends a budget every 4.5 seconds on enemies, spawned in a ring just off screen around the squad, then it rests for 20 seconds. A boss comes at the minute set for it, break or not. The budget, the enemy tiers and the mix of factions grow with time; Heat steps start at 0, 2, 5, 9 and 14 minutes, and each brings in the next tier; they came at 0, 2, 6, 11 and 15 before, with everything piling up at 15:00. The Heat readout beside the XP bar is archived (`rules.SHOW_HEAT`). The mission's difficulty sets the share of the budget and of the cap on enemies alive (`rules.DIFFICULTY_SHARE`: 72% at 5, all of it from 8). At most 40% of a wave's enemies are fast melee rushers (`director.SWARM`); past that, the wave takes the faction's other units. The rosters follow the game's own wave order (`EncounterSettings`): Tripods open the Illuminates' waves there, so they do here too. Observers aren't spawned: each one that sees the squad starts one of the game's encounters. The game's own encounters still run, and the alarm starts one 20 seconds in.

### XP and levels

- Every machine sees every enemy die, so every machine drops the same orb where it died.
- A machine collects the orbs its own players walk over. Orbs another player walks over disappear without XP, because that player's game collects them.
- Each machine shares its collected XP through lobby member data. Team XP is the sum, and every machine works out the same level from it.
- The XP bar's fill eases to the team's XP instead of jumping, runs to the end and starts again from empty on a level-up, and pulses a brighter blue whenever the team's XP goes up (`xp.bar_step`).
- A level-up pauses the game on every machine, each pausing itself as the pause menu does (Obsidian API's `world.time_scale` at 0 with `opts.lobby`, 1.33.1), and makes the local players invulnerable. With an older API the enemies freeze instead (the API's `freeze`, the Trainer's). `TIME_SCALE` alone was tried first: it slows only what the scripts time, so the game kept moving.
- Each machine shares the last level its players finished picking for. Time comes back when every machine has reached the team's level.
- After 45 seconds of real time, a player who hasn't picked gets the card under the cursor.

### Upgrades

An upgrade sets a player's stats (`src/upgrades.lua`), and `src/perks.lua` keeps those on the player's unit and weapons every frame, so a respawn takes the same numbers. Weapon stats go through `api.gear.tune`, which gives one weapon a private copy of its settings, so nobody else's weapon changes. The Shield Generator Pack upgrade and the backpack share one pool (`src/shield.lua`). Peak Physique tunes each weapon's melee the same way (`api.gear.tune(unit, "melee", ...)`): its power, and the swing's duration and delay. The melee state ends when the swing's duration runs out, and nothing else holds the next melee back, so a shorter swing is a faster attack rate; the animation keeps the game's speed. Gunslinger fills the sidearm back after each shot through the weapon's own `set_ammo`, and gives it Weight Training's speed. Trailblazer leaves the Fire elites' napalm fire behind a sprint (`src/trail.lua`). The fire hurts through a status for whoever walks in (`FlowCallbacks.status_area_enter`) and through a blast every half second (`SpawnAreaEffectComponent`), and the player who left it takes neither. Extra Padding's armor goes through the health component's `armor` command, as Heavy Armor's does, since a direct write trips the game's tamper check.

Guard Dog and Angel give the drones of the game's drone packs without the backpack (`api.gear.add_drone`). A drone needs its pack's station to dock, reload and fly around, so the station rides on the player outside the backpack slot, as the game's own `set_backpack` spawns it, and every machine hides a station that isn't its player's backpack. Each pick is one more station and drone. A death takes them, as it drops a worn pack, and the respawn gets them back.

The fight upgrades live in `src/fight.lua`. Obsidian API's `combat.on_hit` (1.12.0) hears this machine's players' hits on every machine's enemies, with the weapon slot: primary damage fills a fire and a poison build-up per enemy (Ignition and Needle Rounds), and Facetanker takes its armor off the power of a hit from the front half of the body before the game prices it (`HealthComponent.calculate_damage`). The statuses go out with `api.enemies.apply_status`, which reaches the enemy's owner. Democracy Protects answers `combat.on_fatal`: a roll spares the player with 1 hitpoint, and the next 0.3 seconds of the same volley too. Unstoppable Freedom adds every status element to the body's own immunities (`src/perks.lua`), as the game does for its immune enemies.

The dive is the game's `CharacterStateDodge`, shared by every character, so `src/dive.lua` looks up whose unit it is. Elusive Tactics scales the dive's speed as it starts and stuns the enemies within 5 m, with the game's 1-second stun again each second or its 3-second one. A dive's getting up runs in `CharacterStateDodge`, or in `CharacterStateCrawl` when the player holds a direction, so both are hooked. A Cyborg Hound's takedown is the "regular_knockdown" status, which puts the player in the same `CharacterStateKnockedDown` as a blast does. Warp Pack teleports the player along the dive as it starts, stopping 0.8 metres short of anything the `mover_blocker` raycast meets, and only onto the level. A card needing a newer API than the one installed names the call in `api`, and isn't offered without it.

Sweet Liberty's blast is Obsidian API's `explode`, at the card's own power. The look comes from the grenade the killer carries (the inventory's `grenade_unit_path`, loaded with the loadout): the particle effect and the sound of that grenade's `explosive_info`, played where the kill fell, as `ExplosionManager.do_explosion` plays them. Each machine shares whether it has a Sweet Liberty player, so the other machines play the same look for that player's kills.

An explosion sends its hits from a physics overlap's answer, and the engine runs that answer on a later step, after the call has returned (the game's own `SpawnManager` waits for one: `waiting_for_overlap`). So `src/hits.lua` filters the hits as that answer sends them: Sweet Liberty and Chain Reaction drop their hits on Helldivers, a Trailblazer patch drops its hits on the player who left it, and the summary marks the hits of the upgrades' blasts and of this machine's grenades.

A card never offers an upgrade at its limit, or one that needs a stratagem the player hasn't unlocked or a field their primary doesn't have, and one row never repeats an upgrade. Every three levels the screen also offers stratagems the player has unlocked, none twice in the row, until they have 12, counting the 4 every player has. The stratagem levels cycle supply, offensive and defensive, and fall back to every category when the player hasn't unlocked enough of one to fill the row. Until everyone has chosen, a player can swap a pick for another: hovered is white, pressed is yellow. What's picked applies when the last player has chosen. Levels also refill health.

### Screens

Cards follow the game's look: dark panels with cut corners, the yellow line, the game's fonts. The rarity colours the card's frame and label, and shapes the badge around its icon: a circle for common, a square for rare, a diamond for legendary. With several local players, the screen splits into a column for each, and each player moves through their own cards with their own controller.

## Multiplayer

Survivors is an Obsidian expansion (`"scope": "expansion"`, Obsidian 1.2.0). Outside the content it counts as a client mod: normal matchmaking, Galactic War results and Proving Grounds. Obsidian keeps the mod's hooks and frame callback, and Obsidian API's guarded calls, off until the content starts, so everything a Survivors drop changes is a hook. The way in runs before that, so it's made of wraps: the galaxy map's tab and Survivors screen with the Refresh button (`src/entry.lua`), the repair of an old saved planet, the loadout's stratagem row (`src/loadout.lua`), and the map preview (`GeneratedLevel.initialize` and `generate_mission` in `src/level.lua`, which make a mission's own map a Survivors one only while the content runs). Obsidian API's `ui.with_texts` is a guarded call, so a copy of it (`entry.with_texts`) puts the Survivors words on the screen. `tests/test_expansion.lua` starts `main.lua` against a fake loader and fails on a guarded call before the content, or on a function moved between the two lists.

The host's pick on the Survivors screen calls `obsidian.expansion.start()` before the galaxy map closes. Obsidian refuses it when a player in the lobby doesn't run Survivors at the same version, and shows the host their names; the galaxy map then stays open on the Survivors screen. Survivors says why for the other refusals (not the host, another expansion running). The content carries on through the repeat drops, and `obsidian.expansion.stop()` ends it when the host picks a campaign mission or a Proving Grounds trial, has no planet left for the hellpods, or reaches the main menu. Closing the galaxy map any other way (Back on the fronts or the first screen) keeps the arcade mission, and the save gets back the planet and trial it had when the map opened. The main menu's stop comes after the game has left the lobby, so it tells nobody: Obsidian hands the content to the next host, as it does when a host leaves mid-mission. A game that takes over the lobby on the ship has no Survivors drop chosen, so it ends the content. Every other game follows the host, and hears it through `obsidian.on_session`: on `true`, Democracy Protects goes in (`api.combat.on_fatal` is guarded); on `false`, the stratagem row and the next drop go back, and a run cut short stops, with `api.effects.clear()` taking off the run's effects, since `effects.set` is refused by then. Survivors makes no custom stratagems (`api.stratagems.define`), which Obsidian doesn't pause.

What the machines agree on goes through lobby member data (`src/sync.lua`), and a few rules keep them agreeing:

- Every machine counts whole samples. Molecular Scan makes shares of one, and a machine that counted its own shares would reach a level the others don't, then wait for them forever.
- A shared value names its mission and its run. Lobby data outlives the mission, so a machine still loading would otherwise show the last run's XP and levels. A run also clears its value as it ends.
- A machine that leaves keeps its XP in the sum, and nobody waits for its choice. Back in the same run, its value takes over; joining with a new run starts from nothing beside the old XP.
- The host shares the run's clock, and a machine more than 3 seconds off takes it. The XP that opens a level-up reaches each machine a moment apart, so the clocks drift a little each level, and a player joining late starts at 0:00. The clock decides when the shuttle can be called.
- A machine that becomes host mid-run picks the director up at the run's clock, with the bosses already come, instead of starting over at minute 0.

With several players on one machine, each picks cards with the controller the game gave them (the player's `pad_number`), and their stratagem upgrades call in as theirs.
